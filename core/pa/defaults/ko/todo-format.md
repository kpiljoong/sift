# Todo 형식 규칙

이 파일은 assistant가 매번 읽는 규칙입니다. 자유롭게 고치고, 예시를 추가하세요.

## 형식 (Obsidian Tasks 호환)
- 한 줄에 하나: `- [ ] <동사로 끝나는 할 일> [📅 YYYY-MM-DD] [#태그...]`
- 마감/날짜가 언급된 경우에만 `📅` 를 붙인다. "내일", "다음 주 금요일" 등은 실제 날짜로 바꾼다.
- 우선순위가 명확히 높으면 `⏫`, 낮으면 `🔽` 를 붙인다. 애매하면 붙이지 않는다.
- 관련 프로젝트가 있으면 `#project/<폴더명>` 태그를 붙인다.
- 원문 링크는 엔진이 자동으로 붙이므로 쓰지 않는다.

## 좋은 예
- [ ] 치과에 전화해서 예약하기 📅 2026-09-27
- [ ] alpha 대시보드 지표 정의 초안 쓰기 #project/alpha

## 나쁜 예
- [ ] 치과 (무엇을 할지 불분명)
- [ ] 내일 치과 전화 (상대 날짜를 그대로 둠)
