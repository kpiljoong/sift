# 일정 형식 규칙

일정이 필요한 내용은 캘린더에 직접 등록하지 않고 `calendar-queue.md` 에 아래 형식으로 정리한다.

## 형식
- [ ] YYYY-MM-DD HH:MM-HH:MM | <제목> | <장소 또는 링크, 없으면 -> | <메모, 없으면 ->

- 종일 일정은 시간 대신 `종일`.
- 시작 시각만 있으면 `HH:MM-` 처럼 종료를 비워 둔다.
- 시간이 아예 불명확하면 `시간미정` 으로 두고 메모에 원문 표현을 적는다.
- 제목 규칙: (예시를 추가해 가르쳐 주세요)

## 좋은 예
- [ ] 2026-09-30 19:00-21:00 | 대학 동기 저녁 | 강남역 | 예약 필요
