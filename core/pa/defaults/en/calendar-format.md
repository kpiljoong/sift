# Calendar format rules

Anything that needs a calendar entry is not added to a calendar directly; it's collected in `calendar-queue.md` in the format below.

## Format
- [ ] YYYY-MM-DD HH:MM-HH:MM | <title> | <place or link, - if none> | <notes, - if none>

- For an all-day event, write `all-day` instead of the time.
- If only the start time is known, leave the end empty, like `HH:MM-`.
- If the time is entirely unclear, write `TBD` and put the original wording in the notes.
- Title rules: (teach them by adding examples)

## Good example
- [ ] 2026-09-30 19:00-21:00 | Dinner with college friends | Gangnam Station | needs a reservation
