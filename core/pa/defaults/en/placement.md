# Placement rules

This vault uses the PARA structure.
- `01-projects/<project>/`: ongoing projects with an end. Project notes, meeting notes, and decisions go here.
- `02-areas/<area>/`: areas you keep managing (career, finance, life, people, etc.).
- `03-resources/<topic>/`: reference material, things learned, links.
- `04-archives/`: finished things. Don't write here.

## Rules
- If it clearly fits an existing project or area folder, create a new note in it or append to the end of an existing note on the same topic.
- Meetings: create `<that folder>/meetings/YYYY-MM-DD <topic>.md`.
- Ideas: if there's no related project, `03-resources/_inbox/ideas/YYYY-MM-DD <title>.md`.
- If you're not sure where it goes, send it to review. Don't force a placement.
- Don't create new folders (projects). If one seems needed, send it to review and give the reason.
- Don't use `/ \ : * ? " < > |` in file names.
